A native flexible table builder block for the Gutenberg Block Editor.

== Description ==

Yen Blocks is a native flexible table builder block for the Gutenberg Block Editor. It allows you to build highly customizable tables with ease.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/yen-blocks` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
